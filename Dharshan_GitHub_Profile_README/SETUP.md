# GitHub Profile README — Dharshan

## Install

1. Create/open your GitHub profile repository:
   `dharshanprabath/dharshanprabath`
2. Put `README.md` in the repository root.
3. Put the `assets` folder beside it.
4. Commit and push.
5. Replace the LinkedIn URL in README.md with your actual profile.

The GIFs are local, so the main animations live inside your own repository.
